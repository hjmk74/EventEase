# EventEase

EventEase is a small Blazor project for managing events. I made it as part of the course project.

## What it has

- Event cards
- Blazor routing
- Event registration
- Form validation
- Simple session state
- Attendance tracker
- Search for attendees
- Responsive CSS

## Run the project

You need the .NET 8 SDK installed.

```text
dotnet restore
dotnet run
```

Then open the address shown in the terminal.

## Project folders

- Components: pages and reusable components
- Models: Event, Registration and AttendanceRecord
- Services: event, session and attendance logic
- wwwroot: CSS
